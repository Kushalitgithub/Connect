# Shared Typed API Client

Generated from the Connect backend OpenAPI schema (`backend/app/main:app` → `/api/v1/openapi.json`).

Files:
- `schema.d.ts` — TypeScript types generated by `openapi-typescript` from the OpenAPI schema.
- `client.ts` — Axios client wrapper with auth interceptor, response interceptor (token refresh), and typed request helpers.

Usage in each frontend app:
```ts
import api from '@/lib/api'   // app-specific thin wrapper extending the shared client
```

The shared client itself is role-agnostic; each app supplies its own token storage (expo-secure-store for mobile, zustand/localStorage for admin).
